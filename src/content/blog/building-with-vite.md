# 用 Vite 构建个人站点

Vite 启动快、配置少，非常适合搭建个人博客这种轻量站点。

## 优点

- ⚡ 极快的冷启动
- 🔥 即时的 HMR
- 📦 基于 Rollup 的生产构建

```bash
# 创建项目
npm create vite@latest my-site -- --template react-ts
```

写作愉快！
