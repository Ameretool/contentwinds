# 在 GitHub 上添加新文章

无需本地 IDE，全程浏览器搞定：

1. 打开仓库的 `src/content/blog/` 目录
2. 点击右上角 **Add file → Create new file**
3. 文件名写 `your-slug.md`
4. 粘贴 frontmatter + 正文
5. 拉到底部 **Commit new file**

由于 Lovable 与 GitHub 双向同步，几秒后预览站就能看到。

> Microblog 同理，目录是 `src/content/microblog/`。
